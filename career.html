Web Developer

A web developer creates and maintains websites. This career requires technical skills, creativity, and problem-solving. Web developers help people and businesses share information online.

Visit my home page or my about page.

What they do

Web developers build websites and make sure they work correctly. They write code to organize information and create features for visitors. They also test websites and fix problems when something does not work as expected.

  • Write and update HTML code.
  • Test websites and fix coding errors.
  • Check that web pages work on different devices.
  • Work with teammates to improve websites.

Skills you need

Technical skills

  • Knowledge of HTML and CSS.
  • Basic knowledge of JavaScript.
  • Ability to find and fix coding errors.

People skills

  • Communication.
  • Teamwork and problem-solving.

How to get started

  1. Take computer science or web design classes.
  2. Learn HTML, CSS, and JavaScript.
  3. Build original websites to practice your skills.
  4. Complete relevant training or a college program if needed.
  5. Apply for an internship or an entry-level web development job.

Certifications and credentials

  • AWS Certified Developer – Associate, offered by Amazon Web Services.
  • CIW Web Foundations Associate, offered by CIW.

Pay and job outlook

According to the U.S. Bureau of Labor Statistics, web developers had a median annual wage of $92,650 in May 2025. The bureau also projects employment for web developers to grow by 4 percent from 2025 to 2035.

Where you could work

Web developers can work for technology companies, online retailers, schools, and financial institutions. They may also work for businesses that create websites for clients or work independently.

Why this career interests me

I am interested in web development because I want to learn how websites are created. I like the idea of using code to build something people can use. One challenge I might face is finding and fixing coding errors, practicing will help me improve my skills.
