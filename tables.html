HTML Tables

The Table Element

<table> - This is the element that creates an HTML Table. NOTE: HTML Tables are used to organize data into rows and columns.

Cell

Cell - It is a location in the table at a specific row and column. Cells are created at the intersection of a row and a column.

Table Row

<tr> - An element that creates a row in a table. Table rows are nested inside of table elements.

Table Header

<th> - An element that creates a cell containing table header information about the data contain in a specific column or row.

Table Data

<td> - An element that creates a data cell in a table. Data cells contain the actual content of the table.

Caption

<caption> - An element that creates a caption or a short descriptive text for the table.
