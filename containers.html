HTML Containers

Container

Any element with an opening and closing tag that holds content

<div>

Generic block container with no meaning of its own. This tag is useless without a class or id attribute.

<span>

Generic inline container with no meaning of its own. This tag is useless without a class or id attribute.

Block vs Inline

A block container (or block element) starts on a new line and take up the full width of their container/parent container, while inline elements do not start on a new line and only take up as much width as necessary.

Semantic Elements

<article> Element - This contains content that can stand alone outside of the context of the current web page.

<aside> Element - This contains content that relates to the current web page indirectly, and is not part of the main content. An example of an aside would be an advertising link on a website, which is often created in a section off the right-side of a page. is an example of an aside.

<footer> Element - This contains content that is at the bottom of the page, and is often used for copyright information, contact information, or links to other pages.

<header> Element - This contains content that is at the top of the page, and is often used for navigation links, logos, or other important information.

<main> Element - This contains the main content of the page.
