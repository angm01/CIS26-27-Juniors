HTML Containers

Container

Any element with an opening and closing tag that holds content

<div>

Generic block container with no meaning of its own. This tag is useless without a class or id attribute.

<span>

Generic inline container with no meaning of its own. This tag is useless without a class or id attribute.

Block vs Inline

A block container (or block element) starts on a new line and take up the full width of their container/parent container, while inline elements do not start on a new line and only take up as much width as necessary.
